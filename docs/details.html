Proof & details

Everything behind the money, in plain words.

How $SHELL launches, how your money is held, the public test transactions you can open yourself, and how the city is tested. Each line here is true today; anything not done yet says so.

1 · The launch

How $SHELL launches

$SHELL launched on pump.fun, from a console at the Exchange inside the game. It launched on __DATE__.

Pressed in game

Only the owner's Roblox account can open the launch console. The game server checks who is pressing, and the backend checks again.

A launch code

The press also needs a secret code that only the backend knows. Wrong codes lock the console for 15 minutes after five tries.

Only once

The backend records the launch before sending it. Pressing again returns that same launch; it can never make a second coin.

A note on chain

The launch transaction carries a memo, a short public note, naming the Roblox game, the game server and the game version it was pressed from.

First buy to the treasury

The launch includes a first buy. A second transaction moves every coin from that buy to the city treasury, so none stays with the launch wallet.

A fresh wallet

The launch is signed by a brand-new wallet used only for $SHELL. The server refuses to start if that wallet has ever done anything else.

The launch proof page lists every launch transaction, the memo, the game server and the Roblox account, so you can check each one yourself.

2 · Your money

How your money is held

Shell City is custodial: the game holds players' $SHELL for them, the way a bank holds money. You never need a wallet, and you never handle a key.

Your own deposit address

Every player gets their own Solana address to send $SHELL to. Only $SHELL is credited, and only once Solana marks the transfer final.

Withdrawals

Paste any Solana address and the amount; the bank shows the fee and what arrives before you confirm. Earned $SHELL can leave once your Street Cred reaches 100, after a few days of play.

Limits and holds

Per-withdrawal and daily limits are set from the launch price and shown in the bank. A player can make 3 withdrawals per 10 minutes. Payouts to a wallet shared by several accounts are held for a person to check.

A ledger you can't edit

Every movement of money is written twice, out of one account and into another, and the two must match. Entries can be added but never changed or deleted.

Books checked against the chain

Every hour the city's records are compared with what its Solana accounts actually hold, and the result is written down. A difference raises an alarm; nothing is quietly corrected.

A pause button

Payouts can be paused with one setting. Requests keep their place in the queue and nothing is lost.

Fees are 5% under 2,500 $SHELL, 3% up to 25,000 and 1.5% above, with a smallest fee of 1 $SHELL; they may be adjusted to the launch price. See how the money works for wages, Street Cred and fees.

4 · Testing

How it's tested

Money code should be dull and well checked. Here is what has been done, and what hasn't yet.

Automated tests

Suites for the backend and the game run on every change, and are themselves checked: run against a fake, empty chain, every chain test must fail.

Break it first

Every fix to a money path is proved by breaking the code on purpose, watching the test fail, then restoring it exactly.

Security review

The money paths have had an internal security review. There has been no outside audit yet.

Mainnet rehearsal

The city-coin code has been rehearsed on Solana's real network with a throwaway coin: launches, trades, buyback and burn, a deposit and a withdrawal, with the books matching.

Load test

Simulated players running one game server for a full session, to find where things slow down.

Test network runs

The in-game launch, deposits and withdrawals have each been run end to end on devnet, with the public transactions above.
