    Check a recording's hash
    
			
    Download the file, then compute its SHA-256 hash:
    
			
    Windows (Command Prompt or PowerShell):
    
			
    certutil -hashfile file SHA256
    
			
    macOS or Linux (Terminal):
    
			
    shasum -a 256 file
    
			
    Replace file with the path of the downloaded file. If the hash it prints matches the one listed for that recording, your copy is byte for byte the file published here.
